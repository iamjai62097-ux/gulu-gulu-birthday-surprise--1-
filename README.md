# Gulu Gulu Birthday Surprise

A static birthday surprise website built with plain HTML, CSS, and Vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser.

## Publish
Upload `index.html`, `style.css`, and `script.js` to a GitHub repository and enable GitHub Pages, or drag the folder into Netlify.

No npm, Node.js, React, Vite, or build step is required.
